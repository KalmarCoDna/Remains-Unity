# Проверки без запуска Unity

Нужны Python 3.9+ и установленный Unity **6000.0.39f1**. Используются его .NET runtime и Roslyn; Editor, графика, сеть и активация лицензии для этого запуска не вызываются. Зависимости из интернета не устанавливаются.

```sh
python RemainsUnity/Tests/Headless/run.py --editor "/path/to/Unity/6000.0.39f1" --output "/path/to/report.json"
```

На Windows передайте путь к установленному `Unity.exe` или каталогу `Editor`. Полные пути с пробелами заключайте в кавычки. Запускайте из корня checkout; сам скрипт разрешает исходники относительно своего расположения.

- `--suite cadence`: существующие `ReplicationCadenceChecks.Run` на настоящем таймере — частота кадров, длительная сессия и остановки без догоняющих пачек.
- `--suite manifest`: существующие `SnapshotManifestChecks.Run` на настоящем `SnapshotManifest`/`TextSha256` — контрольные digest, порядок, изменения, изоляция, ошибки и строгий UTF-8. Только контейнеры входных массивов и интерфейс sink предоставлены в `ManifestInput.cs`; `SnapshotPartCache.Compose` и мир не проверяются.

Без `--suite` выполняются оба набора. Ошибка компиляции или проверки даёт ненулевой код выхода; JSON содержит результаты и SHA-256 исходников. Временные программы удаляются и при ошибке.

`Shims.cs` заменяет вывод Debug и неиспользуемую границу EditorApplication.Exit. Эти файлы лежат вне Assets и не попадают в сборку игры. Запуск не подтверждает импорт проекта, полную компиляцию, физику, UI, сетевой сеанс или сохранность целого мира. Проверка на Windows ещё требуется отдельно.
